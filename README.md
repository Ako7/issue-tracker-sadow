This is a [Next.js](https://nextjs.org/) project bootstrapped with [`create-next-app`](https://github.com/vercel/next.js/tree/canary/packages/create-next-app).

# Wprowadzenie

Dzieki temu projektowi nauczyłem się towrzenia średniozaawansowanych aplikacji fullstack React + Next.js. W składowych projektu zawiera się obsługa bazy danych MYSQL oraz Prisma ORM, obsługa atentykacji użytkowników wykorzystując SessionProvider oraz GoogleProvider. Pisanie API pobierających i walidujących dane z bazy. Korzystanie z Tailwind oraz Radix UI w celu zaprojektowania przejrzystego interfejsu. Tworzenie szkieletów wczytywania w oparciu o react-loading-skeleton oraz powiadomień dzięki react-hot-toast. Wykorzystywanie NextLink, NextImage oraz dynamicznego ładowania komponentów w celu optymalizacji wczytywanych danych. Używanie useRouter oraz useSearchParams do korzystania z parametrów URL oraz modyfikowania ich. Tworzenie formularzy w oparciu o react-hook-form oraz react-simplemde-editor, a także walidacja ich za pomocą zod. Wykorzystywanie react-query oraz axios do pobierania i obsługi danych wykorzystywanych w aplikacji. Podczas tworzenia aplikacji przestrzegałem zasad czystego kodu, usunąłem powstałe redundancje.

# Narzędzia

- Główne: React, Next.js, Typescript
- Baza danych: MYSQL, Prisma ORM
- Autentykacja: NextAuth + Session & Google Provider
- Projekt graficzny: TaiwindCSS, RadixUI, react-loading-skeleton, react-hot-toast
- Poprawa wydajności: NextLink, NextImage, LazyLoading
- Narzędzia do parametrów URL: useRouter, useSearchParams
- Formularze: react-hook-form, react-simplemde-editor, react-markdown, zod
- Wczytywanie danych: ReactQuery, Axios
